# Themes

[Documentation](README.md) · [Customize appearance](settings.md#change-the-theme)

Choose a theme in **Settings → Theme → Appearance**, then **Save**. Midnight is the default.

Every screenshot uses the same document, terminal size, and default role mappings. Themes change the interface; document colors remain independent.
